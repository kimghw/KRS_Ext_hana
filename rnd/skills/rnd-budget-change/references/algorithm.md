# rnd-budget-change 계산 규칙 (budget_calc.py)

## 목적
한 연차의 **직접비 소계·간접비·총액을 고정**한 채, 직접비 비목 간에 금액만 옮긴다.
LLM 암산 금지 — 모든 산술은 `budget_calc.py` 가 전담. 단위 = **천원 정수**.

## 비목 체계
표준 직접비 5비목(고정 순서): `인건비 · 연구시설장비비 · 연구재료비 · 연구활동비 · 연구수당`.
- 표시명: `연구시설장비비` → **연구시설·장비비**(고시 2025-6호 용어 통일). 나머지는 키=표시명.
- 스냅샷이 0원 비목을 생략(`keep_zero_rows:false`)해도 엔진이 5비목을 0으로 채운다 →
  0원 비목을 **도착 비목으로 새로 계상** 가능.
- **인건비는 이동 대상에서 제외**(`BLOCKED`) — 참여연구원 개인별 계상액 재배분이 필요하므로
  `/rnd-manpower-change` 로 유도(출발/도착에 인건비가 있으면 거부).

## 후값 산출
```
after = before.copy()
for m in 이동:            # m = {from, to, 금액}
    after[m.from] -= m.금액
    after[m.to]   += m.금액
```
여러 건의 이동을 순서대로 누적 반영한다.

## 검증 불변식 (모두 통과해야 ok)
1. **표준 비목** — from·to 가 5비목 중 하나.
2. **인건비 미관여** — from·to 에 인건비 없음.
3. **자기이동 금지** — from ≠ to, 금액 > 0.
4. **잔액 ≥ 0** — 모든 비목 after ≥ 0 (출발 비목이 이동액보다 크거나 같아야).
5. **직접비 소계 불변** — Σafter = Σbefore(= 스냅샷 소계).
6. **간접비·총액 불변** — 이동은 직접비 내부 재배분(간접비 base 불변).
7. **이동 순합 0** — Σ(after−before) = 0.

## 2-pass 재검산
후값을 **독립적으로 다시 합산**해 5·6·7 을 교차확인:
```
recheck_subtotal = Σ after[k]
recheck_total    = recheck_subtotal + 간접비
recheck_ok = (recheck_subtotal == subtotal_before)
             and (recheck_total == total_before)
             and (Σ(after−before) == 0)
```
`검증.재검산_일치` 로 노출. `ok = (오류 없음)`, `ok=false` → exit 2.

## 산출물
- `--md-out` → 변경안 MD(제목 `연구개발비 비목 변경 현황` + 3절: 개요·변경요약·변경내역).
- `--yaml-out` → 비교 YAML(top key `연구개발비비목_변경비교`, 비목별 전/후/증감).
- MD·YAML 은 같은 계산 결과에서 나와 100% 일치. `ok=false` 면 두 파일 모두 생성하지 않음.

## 왜 인건비만 다른가
다른 비목은 총괄 금액만 있으면 이동이 완결되지만, 인건비는
`참여연구자인건비.참여자[].계상인건비` 합 = `비목별.직접비.인건비` 라는 개인별 정합이 걸려 있다.
인건비 총액을 바꾸면 개인별 계상률·계상액을 재배분해야 하고, 그건 `/rnd-manpower-change` 의 역할이다.
