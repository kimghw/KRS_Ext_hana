# rnd-budget-change — 연구개발비 비목 간 이동 계산기

한 연차의 **직접비 소계·간접비·총액을 고정**한 채, 직접비 비목 간에 금액만 옮긴다.
"총 변경금액은 이전=이후 동일" — 나간 만큼 들어오므로 소계·총액은 변하지 않는다.

## 비목 체계 (직접비)

| yaml 키 | 표시명(문서·YAML) | 이 스킬 대상 |
|:--|:--|:--|
| `인건비` | 인건비 | ❌ 제외 — 개인별 재배분 필요(→ `/rnd-manpower-change`) |
| `연구시설장비비` | **연구시설·장비비** | ✅ |
| `연구재료비` | 연구재료비 | ✅ |
| `연구활동비` | 연구활동비 | ✅ |
| `연구수당` | 연구수당 | ✅ |

- 스냅샷에서 0원 비목이 생략(`keep_zero_rows:false`)됐어도 엔진이 표준 5비목을 0으로 채워 넣는다 —
  0원 비목(예 연구시설·장비비)을 **도착 비목으로 새로 계상**할 수 있다.
- '연구장비비'는 통칭이고 정식 명칭은 **연구시설·장비비**(고시 2025-6호 용어 통일). 근거: `references/국가연구개발_자료/`.

## 경로 약어

```
proj_dir  = RND_PROJECT\<과제이름>
year_dir  = proj_dir\<연차>                       # 스냅샷 KR_<과제>.yaml 이 있는 폴더
chg_base  = year_dir\budget_change
out_dir   = chg_base\rev<NN>_<작성일>            # 이번 실행 산출물 폴더
pend_root = RND_PROJECT\_pending                  # 전역 검토 큐(_export 관례와 짝)
pend_dir  = pend_root\<과제이름>\<연차>_비목_rev<NN>_<작성일>   # out_dir 사본(회차 폴더 통째)
```

## 절차

- **§0 입력 확정** — 스냅샷·`--project` 로 과제/스냅샷을, `--year` 로 연차를 정한다. 없으면 AskUserQuestion.
  `--품의서`/`--date` 없으면 품의서 유무를 묻고(시행일 > `--date` > 오늘) 작성일·회차(`rev<NN>_<작성일>`)를 정한다.
- **§1 추출** — `budget_calc.py --extract <스냅샷> --year <연차> -o <out_dir>\budget_input_<연차>_rev<NN>.json`.
  스냅샷 `예산.비목별[연차].직접비` 에서 현재 비목·간접비·총액을 뽑아 이동칸이 빈 scaffold JSON 생성(표준 5비목 0 보정).
- **§2 이동 입력** — 출발 비목·도착 비목·이동 금액(천원)을 AskUserQuestion 으로 받아 JSON `이동[]` 에 채운다.
  여러 건 가능. **from/to 는 yaml 키(`연구시설장비비` — 가운뎃점 없음)** 또는 표시명(`연구시설·장비비`) 둘 다 허용
  (엔진이 정규화). 금액은 천원 정수(콤마 허용). **인건비는 출발/도착 후보에서 제외**(선택 시 엔진이 거부·유도).
- **§3 계산·문서** — 출력 경로를 정확히 지정해 실행:
  `budget_calc.py <out_dir>\budget_input_<연차>_rev<NN>.json --yaml-out <out_dir>\연구개발비비목_<연차>_rev<NN>.yaml --md-out <out_dir>\rev안_<연차>_rev<NN>.md`.
  후값 산출 + 2-pass 재검산 + 변경안 MD·비교 YAML 동시 생성. **`ok=false`(exit 2)면 MD·YAML 을 만들지 않으므로**
  오류를 사용자에게 보여주고 이동값을 고쳐 재실행.
- **§4 PDF** — `--no-pdf` 아니면 `md2pdf.py <out_dir>\rev안_<연차>_rev<NN>.md --title "연구개발비 비목 변경 현황"` 로
  PDF 생성(pandoc 있으면 사용, 없으면 내장 변환기).
- **§4.5 pending 복사** — `--no-pending` 아니면 `to_pending.py <out_dir>` 로 방금 만든 회차 폴더를 **통째로**
  전역 검토 큐 `pend_dir`(= `RND_PROJECT\_pending\<과제>\<연차>_비목_rev<NN>_<작성일>`)에 복사한다.
  **원본 `out_dir` 은 그대로 두고 사본만 큐에 올린다**(복사 전용). 경로만으로 과제·연차·종류(비목)·회차를 도출하므로
  추가 인자 불필요 — `python "${CLAUDE_SKILL_DIR}/scripts/to_pending.py" "<out_dir>"`. 같은 회차 재실행 시 사본을 새로 만든다.
  ⚠ `ok=false`(§3 실패)면 out_dir 산출물이 없으므로 이 단계도 건너뛴다.
- **§5 핸드오프** — 스냅샷·이력은 **읽기만**. 확정 시 비교 YAML 의 '후' 값을 스냅샷 `예산.비목별[연차].직접비` 에
  반영 → `/rnd-kr-extract`(재구조화) → `/rnd-kr-history`(스냅샷 budget diff 적재)가 담당(이 스킬은 변경안만 생성).
  ⚠ 비교 YAML(top key `연구개발비비목_변경비교`)은 **검토·수기반영용** — `/rnd-kr-history` 에 **직접 입력하지 않는다**
  (kr-history 의 변경비교 입력모드는 참여연구자인건비 전용. budget 은 스냅샷 경유로만 적재).

## 검증 불변식 (budget_calc.py, 단위 천원 정수)

1. **인건비 미관여** — 출발·도착에 인건비가 있으면 거부(→ `/rnd-manpower-change`).
2. **잔액 ≥ 0** — 출발 비목이 이동 금액보다 작으면(후값 음수) 거부.
3. **직접비 소계 불변** — 이동 후 비목 합 = 이동 전 소계.
4. **간접비·총액 불변** — 이동은 직접비 내부 재배분이므로 간접비·총액을 건드리지 않는다.
5. **이동 순합 0** — Σ(증감) = 0 (나간 만큼 들어옴).
6. **2-pass 재검산** — 후값을 독립적으로 다시 합산해 3·4·5 를 교차확인(`검증.재검산_일치`).
   `ok = (오류 없음)` 이며, `ok=false` 면 exit 2.

## 산출물

`out_dir` = `RND_PROJECT\<과제이름>\<연차>\budget_change\rev<NN>_<작성일>`.

| 산출물 | 생성 조건 | 후속 사용처 |
|:---|:---|:---|
| 변경안 문서 `out_dir\rev안_<연차>_rev<NN>.md` | `budget_calc.py --md-out`(엔진 자동생성) | 협약변경/연차변경 검토자료. 제목 `연구개발비 비목 변경 현황` + 3절(개요·변경요약·변경내역, 비목별 전→후·증감) |
| 변경안 PDF `out_dir\rev안_<연차>_rev<NN>.pdf` | `--no-pdf` 아니고 Edge/Chrome 있음 | 제출·회람용 변경 전/후 비교본(한글 렌더) |
| 변경 전/후 비교 YAML `out_dir\연구개발비비목_<연차>_rev<NN>.yaml` | `budget_calc.py --yaml-out` | 비목별 전/후·증감. 확정 시 '후' 값으로 스냅샷 `예산.비목별[연차].직접비` 반영 → `/rnd-kr-extract` → `/rnd-kr-history` |
| 계산 입력 `out_dir\budget_input_<연차>_rev<NN>.json` | 매 실행 | 재현·재계산(이동 비목·금액 바꿔 재실행) |

## 산출물 명명

| 속성 | 값 |
|:---|:---|
| stem 유도 | 고정 접두 + 연차 + 회차 — 변경안 `rev안_<연차>_rev<NN>`, 비교표 `연구개발비비목_<연차>_rev<NN>`, 입력 `budget_input_<연차>_rev<NN>` |
| suffix | `_rev<NN>`(회차, 2자리). 폴더는 `rev<NN>_<작성일>`(회차+작성일). 회차=`--seq` 또는 자동 증번, 작성일=`--date` 또는 시스템 날짜 |
| 확장자 | 문서 `.md`·`.pdf`, 비교표 `.yaml`, 입력 `.json` (모두 UTF-8, BOM 없음) |
| 사용자 지정 옵션 | `--seq`(회차), `--date`(작성일), `--no-pdf`(PDF 생략), `--from`·`--to`·`--amount`(이동), `--year`(연차) |
| 충돌 처리 | 회차 폴더가 격리 단위 — 같은 회차 재실행 시 폴더 내 파일만 덮어씀. 새 변경은 `--seq` 증번(또는 자동)으로 새 폴더 생성, 기존 회차 폴더는 보존 |

## show / help

- `show` — 지정 과제/연차의 현재 직접비 비목(전값)을 표로 보여주고 끝(계산 없음).
- `help` — 이 스킬 사용법 요약.

## 관계 스킬

- `/rnd-kr-extract` — KR 스냅샷(입력) 생성.
- `/rnd-manpower-change` — 인건비(참여연구원 개인별) 재배분. **인건비 관련 이동은 이쪽.**
- `/rnd-kr-history` — 변경 확정분(비교 YAML '후' 값)을 스냅샷·이력에 적재.
