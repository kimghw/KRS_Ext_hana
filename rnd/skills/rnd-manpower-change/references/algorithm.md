# 인건비 재배분 알고리즘 (reference)

`manpower_calc.py` 의 계산 규칙. 단위는 모두 **천원**.

## 1. 공식 — rerp(회사 연구개발 관리 시스템) 기준

```
월급여     = 급여총액 / 12 → 천원 자리 절삭(내림)          # floor_k
계상인건비 = 월급여(절삭) × 참여기간_개월 × (계상률 / 100) → 천원 절삭
월 참여율  = 월 인건비 / 월급여 × 100 → 소수점 3자리에서 0 초과 시 올림(소수 2자리) — 표시용  # ceil2
최종 계상률 = 계상인건비 / 총 지급한도(월급여 × 개월) × 100 → 소수점 3자리에서 올림 — 공문 표기값  # back_rate
```

### 1.1 rerp 절사·올림 규칙 (요약)

| 값 | 규칙 | 함수 |
|:---|:---|:---|
| 월급여 | 급여총액/12 **천원 절삭**. 평균급여 — 단축근무·단기휴가 시에만 참여자별 `월급여` override | `monthly_salary` |
| 월 참여율 | 월 인건비/월급여×100 — **소수점 3자리에서 0 초과 시 올림** → 소수 2자리 | `ceil2` |
| 최종 계상률(표기) | **계상인건비/총 지급한도(월급여×개월)×100** 을 **소수 3자리에서 올림**(월 참여율 평균 아님) | `back_rate` |
| 참여율→계상인건비 | 월급여×개월×률 **천원 절삭** 후, 최종 계상률이 **요청 참여율을 넘지 않도록 −1천원 보정 루프** | `accrued_rerp` |
| 월별 인건비 | 계상인건비/개월 → **1..N−1월 천단위 올림(ceil)**, **마지막 월 = 잔액**(합 = 계상인건비 정확 일치) | `monthly_split` |

검산(1차년도 rev01 예, rerp):
- 문창재 월급여 floor(69877/12)=5823 → 20% 요청: floor(5823×9×0.20)=**10481**,
  최종 계상률 = ceil2(10481/52407×100=19.99924) = **20.00** ≤ 20 ✓ (보정 불필요)
  월별 = 1165 ×8개월 + 마지막 월 1161 (합 10481), 월 참여율(표시) 20.01 ×8 · 19.94
- 김거화(조정) 월급여 floor(101763/12)=8480 → 잔차 20944 흡수, 월별 2328 ×8 + 2320,
  최종 계상률 = ceil2(20944/76320×100=27.4423) = **27.45** (월 참여율 표시 27.46 ×8 · 27.36)

### 1.2 중도·구간 변경 (`변경적용월`·`변경종료월`) — "나머지/구간 개월" 계산

`분류:변경` + `변경적용월:"YYYY-MM"` 이면 그 월 **이전 개월은 전 월별 배분 금액을 그대로 유지**(지급실적 기준),
**나머지 개월만** `accrued_rerp(월급여, 나머지개월, 신규률)` 로 계산해 월별 배분한다.
`변경종료월:"YYYY-MM"` 도 주면 **[적용월, 종료월] 구간만** 신규률 적용(예: 10월~12월) —
**종료월 이후 월은 전 월별 금액으로 복귀**한다(월별 = 앞 유지분 + 구간 재계산분 + 뒤 유지분).
요청 참여율 초과 금지 보정은 **변경 구간**에 적용. 후 계상인건비 = 유지분 + 구간분(+뒤 유지분),
최종 계상률(공문 표기) = ceil2(후 계상인건비/(월급여×전체개월)×100) — 전체기간 총 지급한도 대비(§1.1).
`분류:제외`(단축, 신규_계상률 없음)도 같은 원리 — 이미 참여한 단축분은 전 월별 금액 유지.

## 2. 분류(category)

| 분류 | 의미 | 후 계상인건비 산출 |
|:---|:---|:---|
| `고정` | 변경 없음·조정 안 함 | 현재값 그대로 |
| `조정` | 변경 없음, 차액 흡수(1~2명) | 잔차배분으로 재계산(아래) |
| `추가` | 신규투입 | (급여총액/12)×신규개월×(신규계상률/100) |
| `제외` | 하차·단축(입력 `삭제`도 동일) | 단축개월로 재계산. 완전 하차(0개월)=0, status 제외. 출력 표기는 `제외` |
| `변경` | 기간·참여율 변경 | 새 개월/계상률로 재계산 |

## 3. 차액 흡수(조정)

```
고정_합계   = Σ(고정 계상인건비)
변경_합계   = Σ(추가·삭제·변경 후 계상인건비)
조정_목표합 = 목표_총인건비 − 고정_합계 − 변경_합계      # 조정연구원들이 합쳐 가질 금액
```

- **목표_총인건비**: 인건비 변경 없으면 현재 `비목별.직접비.인건비`, 있으면 새 값.
- `조정_목표합 < 0` → 변경/고정 합이 목표 초과(불가). 변경안 재검토(`ok=false`).

### 배분 (조정 N명, N=1~2 권장)

- **비례(기본)**: 현재 계상인건비 가중. `alloc_i = round( 조정_목표합 × 현재_i / Σ현재 )`
- **균등**: `alloc_i = 조정_목표합 // N`
- **끝수(잔차) 보정**: `diff = 조정_목표합 − Σalloc` 를 **현재 계상인건비가 가장 큰 조정연구원 1명**에게 가산 → 총액 정확 일치. (소수점 회피)
- N=1 이면 그 1명이 `조정_목표합` 전부.

조정연구원 계상률은 **역산**: `계상률 = 계상인건비 / (월급여(절삭) × 참여기간_개월) × 100` — **소수점 3자리에서 올림(ceil2)**, 정수% 강제 안 함. 조정 행은 금액(잔차 배분)이 1차이므로 rerp 입력 시 참여율 대신 **지급금액(월별)** 기준으로 입력한다(공문 참여율은 표기값).

### 3.1 조정의 구간 배분 (기지급 차감 후 "남은 금액")

조정 참여자에 `변경적용월`(~`변경종료월`)을 주면 **구간 밖 월은 전 월별(기지급) 고정**,
`구간 배분액 = 배분 총액(alloc) − 구간 밖 기지급 합` 만 구간 개월에 `monthly_split` 으로 배분한다
(예: 10~12월에 김거화 축소 — 4~9월 지급분은 그대로, 남은 금액만 10~12월에 재배분).
구간 배분액이 음수(기지급 > 배분 총액)면 `검증.조정구간_음수아님=false` → `ok=false`(구간·변경안 재검토).

### 3.2 연쇄 변경 입력 (`--extract-prev` · 입력 `월별`)

직전 rev 의 변경비교 YAML 을 `--extract-prev` 로 읽으면 '후' 값·**월별인건비(실제 지급액)** 가
다음 회차 입력의 '전' 상태(`계상률`·`계상인건비`·`월별`)로 승계된다(제외자 제외, 회차 자동 +1).
입력 `월별`(합=계상인건비 검증)이 있으면 표준 `monthly_split` 대신 그 실적을 전 월별로 사용 —
구간 변경이 누적돼 월별 패턴이 균등 배분과 다른 경우에도 기지급 월을 정확히 보존한다.

## 4. 제약·검증 (금액 2-pass 재검산 포함)

| 검증 | 조건 | 위반 시 |
|:---|:---|:---|
| 총액 일치 | Σ후_계상인건비 = 목표_총인건비 | `ok=false` |
| 조정목표 음수 아님 | 조정_목표합 ≥ 0 | `ok=false` |
| 참여율 하한 | 모든(추가/변경/조정) 계상률 ≥ floor(기본 10%) | `ok=false`, 조정 인원↑ 또는 변경안 수정 |
| **요청 참여율 이하** | 참여율 구동 행의 역산 계상률(ceil2) ≤ 요청 계상률 | `ok=false`(보정 로직 점검) |
| **월별합 일치** | 모든 행 Σ월별(전/후) = 계상인건비(전/후) | `ok=false` |
| **재검산 일치(금액 한 번 더 계산)** | 재합산 = 목표 **AND** 공식 구동 행(고정/추가/변경/제외)을 `compute_after` 재호출해 금액·월별이 저장값과 **정확히 일치** | `ok=false`, 입력·로직 점검 |
| 계상률 상한 | 조정 후 ≤ 100% | 경고, 조정 인원↑ |

`ok = 총액일치 AND 조정목표≥0 AND 하한충족 AND 요청률이하 AND 월별합일치 AND 재검산일치`. exit 0=ok, 2=실패. 결과 JSON `검증.*` 로 노출.

## 5. 산출 YAML — 변경 전/후 비교 + 월기간

`--yaml-out` 산출(`참여연구자인건비_<연차>_rev<NN>.yaml`)은 **드롭인 교체본이 아니라 변경 전/후 비교본**(검토·기록용):

- 최상위 키 `참여연구자인건비_변경비교`. `소계: {전, 후}`.
- **정보 2종**을 함께 담는다:
  - **① 공문용 `공문용_참여율`**: 참여자별 `{성명, 역할, 분류, 전, 후, 참여기간_후, 변경_적용기간}` — 공문·변경안 문서에 싣는 참여율 정보.
  - **② rerp용 월별인건비**: 참여자별 `월별인건비: [{월: "YYYY-MM", 계상, 참여율}]` — **변경 후 기준** 기록(전/후 비교는 전/후 블록이 담당, 제외자는 생략). **이번 회차에 금액이 바뀐 월엔 `# rev<NN> 변경` 주석**(몇 번째 변경에서 바뀌었는지 — 바뀌지 않은 월엔 없음). `계상` 합 = 후 계상인건비, `참여율` = 월 참여율(소수 3자리 올림). 최하단 `월별_소계: [{월, 계상}]` = 전원 월별 합(합계 = 소계 '후') — rerp 월별 지급 관리·대사값. 파일 머리에 `회차`(몇 번째 변경인지)·`작성일` 명기.
- 참여자마다 `전: {...}` / `후: {...}` 블록을 함께 — `참여기간_개월`·`계상률`·`계상인건비` + **`참여기간: "YYYY-MM ~ YYYY-MM (N개월)"`**.
- 참여자별 **`변경_적용기간`**: 월별 전/후 금액이 달라진 첫 월~마지막 월(`"YYYY-MM ~ YYYY-MM (N개월)"`, 변동 없으면 `-`) — 변경이 **언제부터 언제까지** 적용되는지의 기록. `변경적용월` 입력이 있으면 그 월부터 시작된다.
- 참여기간 = `month_range(시작월, 개월수)`: 종료월 = 시작월 + 개월수 − 1(포함). 시작월(`참여시작`/`신규_참여시작`) 없으면 `"N개월"`, 완전 하차(개월 0·status 제외)는 `"제외"`.
- **스냅샷 반영 시**: 각 참여자의 `후` 값을 `예산.참여연구자인건비` 에 쓰고 `status:제외` 는 표에서 제거(이력은 `/rnd-kr-history`).

`--md-out` 은 **같은 계산 결과**로 변경안 문서(`rev안_<연차>_rev<NN>.md`)를 직접 생성한다 — 제목 `참여연구원 변경 현황`(1회) + **3절(개요[과제·연차·목표총인건비·인건비변경·참여율하한]·변경요약·변경 내역)**, 참여기간 `YYYY-MM ~ YYYY-MM (N개월)`, §3 표에 **변경 적용기간** 열(참여연구자별 언제부터~언제까지), 말미에 rerp 계산기준 각주 1줄, 표는 가운데 정렬. 월별 인건비(rerp용)는 문서에 싣지 않고 비교 YAML 에만. YAML(데이터)·MD(문서)가 한 계산에서 나와 항상 일치. PDF 는 이 .md 를 `md2pdf.py` 로 변환(`--metadata pagetitle` 로 본문 제목 중복 없음). 급여기준자료·월환산·검증·후속조치는 문서에 싣지 않음.

## 6. 끝수가 조정연구원에 몰리는 이유

추가·삭제·변경 각자의 계상인건비를 개별 반올림하면 합이 목표와 1~2천원 어긋날 수 있다. 이 오차를 **조정연구원**(어차피 잔차를 흡수하는 역할)에 몰아 **계상인건비는 모두 정수**로 유지하면서 **총액은 정확히** 맞춘다. 변경/고정 그룹의 금액은 입력 의도 그대로 보존된다.
