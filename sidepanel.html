                        회의실 현황

                        빈 시간을 눌러 예약하세요

                          이 기간에 내 예약·근태로 확인된 건이 없습니다.
                          사이트는 본인 예약에만 수정·삭제 버튼을 붙이는데, 승인 상태에 따라 그 버튼이 없을 수 있습니다. 이름은 e-Class 홈을 열면 자동으로 채워집니다. 아래 설정 → 설정 및 연결에 직접 넣어도 예약자 이름으로 찾습니다.

                            설정연결 · 활동 로그 · 진단
                            설정 및 연결내 이름 · Teams · 공문 · API 키

                            예약자 이름으로도 내 예약을 찾는 데 씁니다. 비어 있으면 e-Class 홈을 열 때 머리글의 사용자 ID 로 인명을 찾아 자동으로 채우고(쪽지의 받는 사람 찾기와 같은 조회), 이 확장으로 예약해도 채워집니다. 직접 고친 이름은 그대로 둡니다.

                            로컬 Claude CLI확인 중

                            연결되면 API 키 없이 이미 로그인된 Claude Code 를 씁니다. 연결되지 않았으면 연결 지침 복사를 눌러 Claude Code·Codex 에 붙여 넣으세요 — 확장 폴더와 등록 방법이 적혀 있습니다.

                            Anthropic API 키CLI 가 없을 때만

                            둘 다 없으면 말로 찾기 칸이 잠깁니다. 키는 이 브라우저에만 저장됩니다.

                            활동 로그기록 없음

                            예약·취소·수정, 근태 신청, 말로 찾기, 조회 실패를 이 브라우저에 최근 500건까지 남깁니다. 문제가 생기면 로그 복사를 눌러 개발자에게 붙여 넣어 주세요. 로컬 Claude 다리의 기록(native\logs)도 함께 담깁니다. 회의 주제와 이름이 들어 있습니다.
